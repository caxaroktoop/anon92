Школа №92 Sakura — учебная версия v1

1) npm install
2) npm start
3) открой http://localhost:3000

Первый зарегистрированный пользователь становится владельцем сайта.
Telegram владельца задаётся в server.js в OWNER_TELEGRAM.

Важно: SQLite подходит для локального обучения. Перед публикацией на Render
перенесём данные в PostgreSQL или настроим постоянное хранилище.
